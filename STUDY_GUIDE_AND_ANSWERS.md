# 📋 QUICK REFERENCE CHEAT SHEET

## The Rules You NEED to Know:

### 1. Number Lines
- **Moving RIGHT** = Adding POSITIVE numbers
- **Moving LEFT** = Adding NEGATIVE numbers
- To find what was added: **End Position - Start Position = What was added**

### 2. Zero Pairs (Additive Inverses)
- Two numbers that add up to ZERO
- Examples: +5 and -5, +100 and -100
- **The opposite of any number is its additive inverse**

### 3. The Double Negative Rule
```
SUBTRACTING A NEGATIVE = ADDING A POSITIVE

a - (-b) = a + b

Examples:
• 5 - (-3) = 5 + 3 = 8
• -10 - (-8) = -10 + 8 = -2
```

### 4. Absolute Value
- **|number|** = Distance from zero (always positive!)
- **|-7|** = 7
- **|7|** = 7
- **Distance between two numbers**: |a - b|

### 5. Solving Equations - The Steps
1. **Undo addition/subtraction FIRST**
2. **Then undo multiplication/division**
3. **Whatever you do to one side, do to the other!**

### Question 2: Solve for 'a'
**Problem:** (-3/4 + 4/3) + a = 0

**Solution:**
1. First, add the fractions: -3/4 + 4/3
   - Common denominator: 12
   - -3/4 = -9/12

   - -9/12 + 16/12 = **7/12**

2. Now: 7/12 + a = 0
3. a = -7/12 (the additive inverse!)

**Answer:** a = **-7/12**

## Lesson 22: Solving Equations

### Problem 1: 5x + 4 = 19
- **Your answer:** x = 3 ✓ (Correct!)
- **Proper steps:**
  1. 5x + 4 - 4 = 19 - 4
  2. 5x = 15
  3. x = 15 ÷ 5 = **3**

### Problem 2: 15x + 14 = 19
- **Your answer:** x = 10 ❌
- **Correct answer:** x = **1/3**
- **Steps:**
  1. 15x + 14 - 14 = 19 - 14
  2. 15x = 5
  3. x = 5 ÷ 15 = **5/15 = 1/3**

### Problem 3: Computer Monitor ($325, $65 more than half original)
- **Equation:** 325 = 65 + (1/2)x
- **Steps:**
  1. 325 - 65 = (1/2)x
  2. 260 = (1/2)x
  3. 260 × 2 = x
  4. x = **$520** (original price)

### Problem 4: 2(x + 4) = 18
- **Your answer:** x = 5 ✓ (Correct!)
